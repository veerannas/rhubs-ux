# RHubs UX — Platform Design Assets

RHubs UX contains the UI/UX design specifications and visual assets for the ReserveHubs platform. These Adobe XD files define the complete design system — screen layouts, interaction flows, typography, color palette, and component states — used as the source of truth for building the RHubs UI frontend and marketing collateral.

The design artifacts cover both the consumer-facing booking interface and the business-owner management portal, with poster/promotional material designs for marketing campaigns.

## Contents

| Asset | Description |
|-------|-------------|
| **ReserveHubs Website.xd** | Full website design — all pages, responsive breakpoints, component library |
| **RHubsPosters.xd** | Marketing collateral — promotional posters and campaign visuals |

## Design Coverage

| Area | Screens |
|------|---------|
| **Consumer Flow** | Discovery, search results, business profiles, booking, reviews |
| **Business Portal** | Dashboard, listings, appointments, notifications, analytics |
| **Marketing Pages** | Home, about, product, career, contact |
| **Responsive** | Desktop, tablet, and mobile breakpoints |

## Tech Stack

- Adobe XD (design & prototyping)
